# MEMORY: Контекст проекта MY SUP SUN

- **Опубликованный сайт:** https://pavelgalkin1985-dot.github.io/my-sup-sun-website2/
- **Бренд:** MY SUP SUN
- **Локация:** Лазаревское, Чёрное море
- **Тематика:** SUP-прогулки, прокат, обучение, SUP-йога, фотосъёмка на воде
- **Визуальная цель:** Дорогой атмосферный водный лендинг
- **Будущие улучшения:**
  - Улучшение секции Hero (заглавного экрана);
  - Эффекты воды, глубокие анимации;
  - Саунд-дизайн;
  - Премиальные карточки туров/услуг;
  - Доработка мобильной версии.

## Текущий технический статус
- Проект переведён на сборщик Vite + локальный Tailwind CSS (версия 3).
- Исходный код разбит на компоненты:
  - HTML — в корне (`index.html`);
  - CSS — в `src/style.css`;
  - JS — в `src/script.js`.
- **Обязательная проверка после любых изменений:** запуск команды `npm run build`.
