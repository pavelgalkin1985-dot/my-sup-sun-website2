## Важно:
- Это отдельный проект сайта;
- НЕ смешивать с Telegram-ботом LAB Pavel Galkin;
- НЕ использовать команды и архитектуру проекта `lab-pavel-galkin-bot-cloud`;
- Работать маленькими итерациями;

- После правок всегда запускать `npm run build`;
- Не делать большой рефакторинг без необходимости;
- Не трогать unrelated-файлы;
- Следить за корректностью для GitHub Pages;
- Учитывать, что сайт публикуется по базовому пути `/my-sup-sun-website2/`.
